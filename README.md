## Getting Started

1. Run `npm install`
2. Run `npm run dev`

## Pricing CSV management

Set the server-only `PRICING_ADMIN_SECRET` environment variable in Vercel (and in the local server environment when using the API locally), then open `/admin/pricing`. The page can filter by Gender and Collection, and exports Product ID, Item Code, Product Name, Gender, Collection, Selling Price, and MRP. After editing the Selling Price and MRP columns, upload the CSV to update the Appwrite products collection.
